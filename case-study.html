Finora Mobile Banking

A calm and secure money-management experience focused on transaction clarity and fast interaction.

Role Lead Android Engineer
Platform Android 8+
Architecture Clean + MVI
Stack
01 · Context

Designing confidence into everyday financial actions.

The product needed to make money movement feel simple without hiding important information. Every critical action needed clear feedback, predictable state, and secure handling.

02 · Problem

Users needed clarity before commitment.

The main challenge was balancing a fast interaction model with the level of detail required for financial decisions.

03 · Architecture

A layered system designed for change.

  • Presentation layer with Compose and state-driven screens.
  • Domain layer with isolated business use cases.
  • Data layer with repository abstractions.
  • Secure local storage for sensitive session information.
  • Automated tests for critical user journeys.
04 · Outcome

Quality became part of the product experience.

The result was a mobile experience with deliberate motion, readable states, secure data handling, and a delivery workflow that supported continuous improvement.
