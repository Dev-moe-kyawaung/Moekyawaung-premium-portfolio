Compose pattern

State should drive the interface. 

@Composable
fun ProfileScreen(
    viewModel: ProfileViewModel = hiltViewModel()
) {
    val state by viewModel.uiState
        .collectAsStateWithLifecycle()

    when (state) {
        ProfileUiState.Loading ->
            LoadingContent()

        is ProfileUiState.Success ->
            ProfileContent(state.profile)

        is ProfileUiState.Error ->
            ErrorContent(
                onRetry = viewModel::retry
            )
    }
}
Architecture pattern

Boundaries make change safer.

Presentation → UI, ViewModel, state
Domain → entities, use cases, contracts
Data → APIs, database, repository implementations
Infrastructure → monitoring, build, delivery
